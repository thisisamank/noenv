November 13, 2026CLI 0.2.0

Agents, Wrangler push, and named accounts

Coding agents and CI get their secrets with one command, secrets push to Cloudflare Workers, and one CLI works with several teams.

Added

  • noenv exec -- CMD runs a command with the secrets of the repository in the current directory. It is for coding agents, scripts, and CI, where the cd hook does not run.
  • noenv wrangler [KEY…] pushes secrets to your Worker with wrangler secret bulk. Without keys, it shows a list to pick from.
  • A [wrangler] section in .noenv pushes the listed keys after each secret set and secret rollback.
  • noenv secret set reads a piped value, so agents can save a secret without a prompt.
  • noenv account add NAME URL [PREFIX…] saves a deployment as a named account. Repositories under a prefix such as github.com/acme use it.
  • noenv account list, account default, and account remove.
  • noenv auth NAME signs in to one account.
  • When you cd from a repository of one account to a repository of another, noenv unloads the first set of secrets and loads the second.

Changed

  • A cd decrypts the last bundle on your machine and makes no network request. A background refresh loads newer values when they arrive.
  • noenv init creates a .noenv file. Commit it, so access problems show as messages instead of silence.
November 1, 2026CLI 0.1.1

CLI on npm, email invites, and a new name

The product is now noenv, the CLI installs from npm, and invites can go out by email.

Added

  • The CLI is on npm as @thisisamank/noenv-cli. The command stays noenv.
  • Invites and the first admin's setup link can go out by email through Cloudflare Email Sending. Set EMAIL_FROM to turn it on.
  • This website, with the 40-second tour.

Changed

  • nenv is now noenv. The old website address redirects to the new one.
  • The Deploy button no longer asks for an email sender. Keep EMAIL_FROM as none to send invite links yourself.
  • Polished the dashboard and the page the Worker serves.
October 31, 2026First release

First release

Encrypted environment variables that load when you cd into a repository, on your own Cloudflare account.

Added

  • Secrets load when you cd into a git repository and unload when you leave. zsh and bash.
  • Values are encrypted on your machine. The Worker stores only ciphertext.
  • Every change is a new version, with history and rollback.
  • Sign-in with passkeys. Roles: reader, editor, and admin.
  • noenv migrate moves .env files in and verifies every value.
  • .env policies (warn, block, migrate, delete), minimum CLI version, and session expiry.
  • The dashboard: projects, secrets, team, policies, and devices.
  • One-click Deploy to Cloudflare.

Fixed

  • The Deploy button build failed on an old package name in the lock file.
